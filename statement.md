
# Student Performance Analyzer

## Problem Statement

Keeping student marks manually can take time and may cause calculation mistakes. This project provides a simple Python program to store student details and analyze their performance based on marks.

The program calculates total marks, average, percentage, grade, and Pass/Fail result for a student.

## Scope

This project is a basic command-line Python application.

It allows the user to:

* Add student details
* Enter marks for three subjects
* View student records
* Analyze student performance
* Save student data in a text file

The project does not use a database, graphical interface, web application, or machine learning.

## Target Users

* Students learning Python
* Beginners practicing Python programming
* Teachers demonstrating basic student record management

## High-Level Features

* Add student name and roll number
* Enter marks for three subjects
* View stored student records
* Analyze a student using roll number
* Calculate total and average marks
* Calculate percentage
* Assign grades
* Display Pass/Fail result
* Save student data to a text file
* Menu-driven command-line interface
